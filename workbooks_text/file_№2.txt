4. Краткая теория
4.1. Что такое HTML
HTML — это язык гипертекстовой разметки, который используется для описания структуры веб-страницы.
HTML отвечает за смысловую структуру страницы:
где находится шапка сайта;
где расположено меню;
где основное содержимое;
где находится карточка товара или информационный блок;
где расположен подвал сайта.
HTML не отвечает за внешний вид страницы. За оформление отвечает CSS.

4.8. Наследование и 
каскадность
Некоторые CSS-свойства наследуются от родительского элемента к дочерним.
Например, если задать шрифт для 
body
, он будет применён ко многим вложенным элементам:
body {
  font-family: Arial, sans-serif;
}
Каскадность
 означает, что если одно и то же свойство задано в нескольких местах, браузер выбирает итоговое значение с учётом приоритета селекторов и порядка правил.
На данном занятии не требуется глубоко разбирать специфичность CSS. Достаточно понимать:
правила ниже по файлу могут переопределять правила выше;
классы обычно удобнее для оформления повторяющихся блоков;
не следует злоупотреблять 
id
 и 
inline
-стилями.
4.9. Блочная модель CSS
Каждый HTML-элемент на странице браузер воспринимает как прямоугольную область. Эта область называется блочной моделью.
Блочная модель состоит из четырёх частей:
Часть
Назначение
content
содержимое элемента: текст, изображение, вложенные элементы
padding
внутренний отступ между содержимым и рамкой
border
рамка элемента
margin
внешний отступ между элементом и соседними блоками
Пример
:
.product
-card {
  padding: 16px;
  border: 1px solid #dddddd;
  margin-bottom: 16px;
}
В этом примере:
padding
: 16px;
 добавляет внутренний отступ внутри карточки;
border: 1px solid #dddddd;
 
добавляет
 
рамку
;
margin-bottom
: 16px;
 добавляет внешний отступ снизу между карточками.
4.10. Модели 
content-box
 
и 
border-box
В CSS есть два основных способа расчёта размеров элемента.
content-box
Это стандартная модель браузера по умолчанию.
Если указать:
.
card
 {
  
width
: 300px;
  
padding: 20px;
  border: 2px solid #dddddd;
}
то итоговая ширина блока будет больше 300px, потому что 
padding
 и 
border
 добавляются к указанной ширине.
Итоговая ширина:
300px + 20px + 20px + 2px + 2px = 344px
border-box
В модели 
border-box
 указанная ширина уже включает 
content
, 
padding
 и 
border
.
.card
 {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid #dddddd;
}
В этом случае итоговая ширина блока останется 300px.
Поэтому в современных проектах часто в начале CSS-файла добавляют правило:
* {
  
box-sizing
: 
border-box
;
}
Это делает расчёт размеров элементов более понятным и предсказуемым.
4.11. Минимальный сброс стилей
У браузеров есть встроенные стили по умолчанию. Например, у 
body
 есть внешний отступ, у списков есть маркеры и отступы, у заголовков — свои размеры и отступы.
Чтобы страница вела себя предсказуемо, в начале CSS-файла часто добавляют минимальный сброс стилей.
Для текущей практической работы достаточно такого варианта:
* {
  box-sizing: border-box;
}
body {
  
margin
: 0;
}
Что делает этот код:
* {
  
box-sizing
: 
border-box
;
}
Правило применяется ко всем элементам страницы. Оно меняет расчёт ширины и высоты элементов так, чтобы 
padding
 и 
border
 входили в общий размер блока.
body
 {
  
margin
: 0;
}
Это правило убирает стандартный внешний отступ браузера у страницы. Если его не убрать, вокруг сайта может появиться нежелательный белый зазор.
На данном этапе не нужно подключать большой CSS-
reset
 или 
normalize
-файл. Достаточно минимального сброса, чтобы студенты понимали, какие стили они задают сами, а какие добавляет браузер.
