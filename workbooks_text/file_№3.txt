4. Краткая теория
4.1. Для чего нужны формы
Форма — это основной способ получения данных от пользователя на сайте.
С помощью формы можно получить:
имя пользователя;
e-mail
;
телефон;
выбранный товар или услугу;
дату;

В интернет-магазине или каталоге услуг форма может использоваться для оформления заявки, заказа обратного звонка или отправки вопроса.

4.6. Что такое модальное окно
Модальное окно — это всплывающее окно, которое временно перекрывает основное содержимое страницы и требует действия пользователя.
В данной практической работе модальное окно используется для формы заявки.
Для реализации модального окна рекомендуется использовать HTML-элемент
