4. Краткая теория
4.1. Зачем нужны 
Flexbox
 и Grid
В ранних версиях веб-вёрстки элементы часто размещали через таблицы, плавающие блоки 
float
 или ручные отступы. Такой подход был неудобен и плохо масштабировался.
В современной CSS-вёрстке для раскладки чаще всего используются:
Flexbox
 — для размещения элементов в одном направлении;
CSS Grid
 — для построения двумерных сеток из строк и колонок.
Оба инструмента могут использоваться в одном проекте, но решают разные задачи.
4.2. 
Flexbox
Flexbox
 удобно использовать, когда элементы нужно расположить в одну линию или в один столбец.
Типичные задачи 
Flexbox
:
горизонтальное меню;
выравнивание элементов в шапке;
расположение кнопок в строку;
выравнивание элементов внутри карточки;
управление промежутками между элементами.
Чтобы включить 
Flexbox
, контейнеру задаётся свойство:
.site
-
nav__list
 {
  display: flex;
}
Пояснение к коду:
display
: 
flex
 делает элемент 
flex
-контейнером;
его дочерние элементы начинают располагаться по 
flex
-правилам;
направление по умолчанию — горизонтальное, то есть 
row
.

4.4. CSS Grid
CSS Grid используется, когда нужно управлять и строками, и колонками.
Типичные задачи Grid:
сетка карточек товаров;
макет страницы «контент + боковая колонка»;
блок преимуществ;
сетка категорий;
сложные страницы с несколькими областями.
Чтобы включить CSS Grid, контейнеру задаётся свойство:
.
products
-grid
 {
  
display
: 
grid
;
}

4.8. Что использовать: 
Flexbox
 или Grid
Ориентир простой:
Задача
Лучше использовать
Горизонтальное меню
Flexbox
Выравнивание кнопок
Flexbox
Карточки товаров в несколько колонок
Grid
Страница «фильтры + список товаров»
Grid
Раскладка элементов внутри одной карточки
Flexbox
Сложная двумерная сетка
Grid
В одном проекте 
Flexbox
 и Grid обычно используются совместно.
