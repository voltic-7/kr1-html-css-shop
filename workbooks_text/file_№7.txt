4. Краткая теория
4.1. Что такое БЭМ
БЭМ — это методология именования CSS-классов.
Название БЭМ расшифровывается так:
Часть
Значение
Б
блок
Э
элемент
М
модификатор
Главная идея БЭМ: интерфейс страницы делится на независимые компоненты, у которых есть понятные имена классов.
БЭМ помогает избежать ситуации, когда в CSS появляются классы вроде:
.red
 {
  color: red;
}
.big
 {
  font-size: 32px;
}
.left
-block div p {
  margin-bottom: 20px;
}
Такие классы плохо объясняют назначение элемента и усложняют дальнейшую поддержку проекта.
4.2. Блок
Блок — это самостоятельный компонент интерфейса, который можно использовать повторно.

4.7. БЭМ и вложенность CSS
Одна из целей БЭМ — уменьшить вложенность CSS-селекторов.
Плохо

-

-

-card h3 {

 {

}
Класс напрямую указывает, какой элемент оформляется.
4.8. БЭМ и 
id
В рамках CSS-рефакторинга не рекомендуется использовать 
id
 для стилизации.
Плохо
:
#popular {
  padding: 40px;
}
Лучше
:
.section
 {
  padding: 
var(
--space-xl) 0;
}
id
 можно использовать для якорных ссылок и JavaScript, но не стоит использовать его как основной инструмент CSS-оформления.
4.9. БЭМ и CSS-переменные
БЭМ отвечает за имена компонентов, а CSS-переменные — за значения оформления.
Они хорошо работают вместе.
Пример:
.product
-card {
  padding: 
var(
--space-md);
  border: 1px solid 
var(
--color-border);
  border-radius: 
var(
--radius-md);
  background-color: 
var(
--color-
bg
);
}
Здесь:
product-card
 — БЭМ-блок;
var
(
--
space-md
)
 и другие переменные берут значения из дизайн-токенов;
структура классов и значения стилей разделены.
